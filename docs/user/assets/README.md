# 资产

资产是场景里可以引用的文件,都在项目内容根(`projects/default/assets/`)下;引用路径相对于内容根。

## 类型一览

| 扩展名 | 是什么 | 怎么来 |
| --- | --- | --- |
| `.wd` | 场景:实体树 + 组件 | 编辑器里新建 / 保存 |
| `.wmodel` | 模型资产:网格、节点、动画、材质槽 | 从 `.gltf` / `.glb` 导入 |
| `.wmat` | 材质资产:贴图引用与参数 | 导入模型时生成,或在编辑器里新建 |
| `.wtex` | 纹理资产:设置 + 指向源图 | 导入纹理时生成(见下"纹理") |
| `.wprefab` | 预制体:可复用的一段实体子树 | 编辑器里把实体保存为预制体 |
| `.wpak` | 内容包 | 打包产物(见[打包](../packaging/README.md)),不是手写文件 |

## 导入模型

- `.gltf` / `.glb` 是**导入源**,不是可引用资产:双击、拖进编辑器或走 Import 流程后,
  产物是 `.wmodel`(外加材质与贴图),之后引用的一律是 `.wmodel`。
- 导入设置(缩放、朝向等)**保存在 `.wmodel` 自身**的元数据块里;改设置后按 **Reimport** 重新导入才生效。
- 模型面板显示源文件、导入设置、网格统计、材质槽与节点树,并带预览(轨道旋转 / 缩放,双击或 `F` 聚焦)。

## 纹理

- 内容树里放**源图**(`.png` / `.jpg` / `.tga` / `.bmp`);导入后得到 **`.wtex` 资产** —— 它是设置的唯一家,
  用 `source:` 指向源图。**没有** `Icon.png.wtex` 这类旁路设置文件。
- 打包烘焙出 `.wtexc` 产物(自描述头 + mip 数据,进内容包;不手改、不出现在内容浏览器)。
  没有 `.wtex` 的源图仍可按引擎默认设置使用。
- 材质与属性里的纹理引用可以指向 `.wtex`;未烘焙时运行时会回退到源图,下拉里显示的是内容根下的完整逻辑路径。
- 改设置改 `.wtex`(不会改写源图);细节见开发者文档 [纹理导入](../../dev/texture-import.md)。

## 引用与移动

- 场景、材质与组件里的资产引用按相对内容根的路径记录;移动或改名后,要在引用它的地方同步。
- 资产格式版本不匹配时,引擎会拒绝加载并提示重新导入(旧版模型资产用 Reimport 重做)。

## 常见问题

| 症状 | 先查什么 |
| --- | --- |
| 导入后看不到模型 | 模型面板里的缩放 / 朝向设置;源文件本身是否正常 |
| 贴图丢失 | 贴图是否被移出内容树;必要时重新导入 |
| 改了导入设置没效果 | 需要 Reimport(设置与产物一起烘焙) |
