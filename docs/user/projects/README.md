# 项目(新建 / 打开 / 目录含义)

> 面向**做游戏的人**。改引擎看 [`../../dev/project-standard.md`](../../dev/project-standard.md)。

## 新建项目

编辑器 `文件 ▸ 新建项目…`:

1. **位置**:点"浏览…"选一个目录(可以在仓库外,例如 `D:\MyGames`);
2. **名称**:合法的项目名(字母/数字/下划线,不能为空);
3. "将创建"会实时显示落点 `<位置>/<名称>`;目录已存在且非空、名称非法、位置不可写都会被拦下;
4. 可选项 **包含最小可运行场景(相机 + 方向光)**(默认勾选):勾上 => 启动就能看见画面;
   不勾 => 场景为空,启动后是空画面(引擎会给提示);
5. 创建后可以:
   - **在资源管理器中打开**;
   - **打开项目**:编辑器重启并切到该项目;
   - **启动项目**:直接起一个独立的运行时进程跑该项目(不需要先切项目、不需要重启编辑器;
     没构建过 `Runtime` 目标时会给出一行构建命令)。

新建出来的项目是**你选的那个模板**(清单 + 资产目录 + 项目 C++ 层 + 场景):
选"干净骨架"就只有骨架,选"示例"会带上示例场景/材质/预制体/脚本/着色器。
示例内容在引擎仓库的 `templates/project-example/**`(模板是引擎的一部分,不会再在引擎里塞一个"默认项目")。

## 项目启动器(启动时先选项目)

编辑器启动时:

- 带 `--project <路径>`(或环境变量 `WLD_PROJECT_DIR`) => 直接进那个项目;
- 否则若开着 **启动时自动打开上次项目**(默认开,偏好里可关)且上次项目还在 => 自动进它;
- 否则显示**项目启动器**:最近项目列表、`新建项目…`、**`新建示例项目…`**(预选示例模板)、`打开项目…`、`退出`。

也就是说:引擎不再"默认替你打开示例项目"——想看示例就点"新建示例项目…"。

## 项目里有什么

| 路径 | 作用 |
| --- | --- |
| `project.we.yaml` | 项目清单:内容根、启动场景、渲染/物理设置(编辑器"项目设置"面板改的就是它) |
| `assets/` | 内容根:场景、模型、材质、纹理、预制体、Lua 脚本都放这里(路径写相对它的) |
| `levels.welevel` | 关卡清单(关卡 id → 场景),可选 |
| `src/` | **项目的 C++ 层**(组件与脚本);引擎代码不在这里,它随引擎走 |
| `.vscode/`、`.luau-lsp/` | Lua 补全/诊断的编辑器配置,可选 |

## 打开已有项目

- 编辑器:`文件 ▸ 打开项目…`,或 `文件 ▸ 最近项目 ▸ …`;
- 命令行:`Editor.exe --project <项目根>`;或设置环境变量 `WLD_PROJECT_DIR=<项目根>` 再启动;
- 运行时:在项目根目录(或者含 `project.we.yaml` 的目录)启动 `Runtime.exe`;
- 找不到清单时启动日志会直接报"哪儿没有 `project.we.yaml`",不会静默用别的项目顶上。

## 启动项目(独立运行)

`运行 ▸ 启动项目(Runtime)`(以及新建成功态里的"启动项目"按钮)会用独立进程启动运行时:
它按项目清单的 `start_scene` 起场景,工作目录 = 项目根 —— 这是最接近发布形态的跑法。
编辑器内的 Play / Simulate 仍是"在当前项目里跑当前场景",两者互补。

### 在项目目录里直接双击启动

新建项目时会在项目根放好两个**自带启动器**(本机产物,已加进项目的 `.gitignore`):

| 文件 | 作用 |
| --- | --- |
| `<项目名>-Edit.exe` | 用本机引擎打开**这个**项目(等价 `Editor.exe --project "<项目根>"`) |
| `<项目名>-Play.exe` | 直接跑这个项目(等价 `Runtime.exe --project "<项目根>"`) |

它们是极小的零依赖 exe(名字带项目名,多个项目放在一起也不会混),复制到别的项目目录也一样能用
(引擎位置是生成时写死的本机路径)。如果构建目录里还没有这两个 exe,向导会退一步生成
`<项目名>-Edit.cmd` / `<项目名>-Play.cmd`(可用 `WE_ROOT` 环境变量指向别的引擎副本)。

### 编辑器本身就是"项目启动器"

不带参数双击 `Editor.exe` ⇒ 直接进**项目启动器**(不会再先替你打开示例项目):
最近项目 / 新建项目… / 打开项目… / 打开默认**示例**项目 / 退出;选中项目后才进编辑器界面。
想"启动就进上次的项目",在偏好里打开 `启动时打开上次的项目`(默认关)。

启动器里可以:

- 用**搜索框**按名称/路径过滤最近项目(最多保留 30 条);
- 任意条目右侧 `删除…` —— 弹一个确认框(确认 / 取消),确认后**永久删除磁盘上的项目目录**:
  文案会写明"该目录及其全部内容将被永久删除,**不会进入回收站**,也无法恢复"。请当成**不可撤销**对待。
- 目标会被拒绝的情况:盘根、引擎仓库本身或它的上层目录、仓库内的目录(引擎与模板)、
  没有 `project.we.yaml` 的目录、以及编辑器当前正打开的那个项目。
- 目录**已经不存在**的旧条目(比如你在资源管理器里删过):同一个确认框会提示"该目录已不存在",
  按钮变成 `从列表移除` —— 只清列表,不动磁盘。

## 常见问题

- **打开后资产面板是空的?** 先看启动日志里挂载的内容根路径;清单里 `content_root` 写的是相对清单目录的路径。
- **改了清单要重启吗?** 渲染/物理的一部分字段下次启动生效(清单注释里有标注),编辑器"项目设置"面板会写回同一个文件。
- **项目的 C++ 代码在哪编译?** 当前用外部 Visual Studio;独立工程化(每个项目自己的构建)在后续阶段。
- **启动项目后是一片黑?** 项目场景里没有相机/灯光。用"包含最小可运行场景"新建,或自己在场景里放一台
  相机(`Primary`)与一盏方向光 —— 没有灯光的场景也是黑的。
