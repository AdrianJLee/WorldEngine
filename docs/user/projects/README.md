# 项目(新建 / 打开 / 目录含义)

> 面向**做游戏的人**。改引擎看 [`../../dev/project-standard.md`](../../dev/project-standard.md)。

## 新建项目

编辑器 `文件 ▸ 新建项目…`:

1. **位置**:点"浏览…"选一个目录(可以在仓库外,例如 `D:\MyGames`);
2. **名称**:合法的项目名(字母/数字/下划线,不能为空);
3. "将创建"会实时显示落点 `<位置>/<名称>`;目录已存在且非空、名称非法、位置不可写都会被拦下;
4. 创建后可以:
   - **在资源管理器中打开**;
   - **打开项目**:编辑器重启并切到该项目(下次启动也会记得用 `--project`/`WLD_PROJECT_DIR` 指过去)。

新建出来的项目**只有骨架**(清单 + 空的资产目录 + 项目 C++ 层 + 空场景),
**不含任何示例** —— 示例都在默认项目 `projects/default` 里,想参考就直接打开它。

## 项目里有什么

| 路径 | 作用 |
| --- | --- |
| `project.we.yaml` | 项目清单:内容根、启动场景、渲染/物理设置(编辑器"项目设置"面板改的就是它) |
| `assets/` | 内容根:场景、模型、材质、纹理、预制体、Lua 脚本都放这里(路径写相对它的) |
| `levels.welevel` | 关卡清单(关卡 id → 场景),可选 |
| `src/` | **项目的 C++ 层**(组件与脚本);引擎代码不在这里,它随引擎走 |
| `.vscode/`、`.luau-lsp/` | Lua 补全/诊断的编辑器配置,可选 |

## 打开已有项目

- 编辑器:`Editor.exe --project <项目根>`;或设置环境变量 `WLD_PROJECT_DIR=<项目根>` 再启动;
- 运行时:在项目根目录(或者含 `project.we.yaml` 的目录)启动 `Runtime.exe`;
- 找不到清单时启动日志会直接报"哪儿没有 `project.we.yaml`",不会静默用别的项目顶上。

## 常见问题

- **打开后资产面板是空的?** 先看启动日志里挂载的内容根路径;清单里 `content_root` 写的是相对清单目录的路径。
- **改了清单要重启吗?** 渲染/物理的一部分字段下次启动生效(清单注释里有标注),编辑器"项目设置"面板会写回同一个文件。
- **项目的 C++ 代码在哪编译?** 当前用外部 Visual Studio;独立工程化(每个项目自己的构建)在后续阶段。
