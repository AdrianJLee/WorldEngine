# 编辑器

从仓库根启动:`.\build\x64-Debug\Editor\Debug\Editor.exe`(构建见[构建与运行](../../dev/build.md))。
不带参数时从空场景起步;打开已有场景用内容浏览器双击 `.wd`,或启动时带 `-scene <路径>`。

## 面板

| 面板 | 做什么 |
| --- | --- |
| View(视口) | 看场景、选实体、导航(2D 俯视 / 3D 透视) |
| Hierarchy | 实体树:选中、改名、父子关系 |
| Properties | 选中实体的组件与字段 |
| Content Browser | 浏览内容根下的资产;双击打开场景 / 材质 / 脚本 / 模型 |
| Project Settings | 项目级设置:渲染(后端、阴影、MSAA、渲染倍率等)、物理等,写回 `project.we.yaml` |
| Editor Preferences | 编辑器自身偏好(语言、主题、缩放等) |
| Stats / Memory / Operations | 性能、内存与操作记录 |
| Scripts / Save / Levels / Input Map / Widget Gallery | 脚本、存档、关卡、输入映射与控件样例 |

材质编辑器、模型面板、Prefab 面板、脚本编辑器是**动态面板**:双击对应资产时打开,默认附加到主窗口,
也可以拖出来变成独立窗口。

## 视口

- 左上角的 `视图 ▼` 是"看"的选项集合:3D ↔ 2D 视角、摄像机预览、光照范围、碰撞体轮廓等。
- 上方居中是运行控制:`Play` / `Simulate` / `Pause`;右上角是只读状态徽标(edit / play / simulate / paused)。
- 场景画面铺满整个视口面板;浮在它上面的按钮不占布局空间(不会把渲染目标挤变形),
  浮层区域也不会误触发视口里的点选。
- 导航:2D 档是平移 / 缩放,3D 档是轨道旋转 / 平移 / 缩放;悬停控件会看到对应按键提示。

## 属性面板

- 面板按**组件 schema**生成:字段怎么编辑(数值、颜色、资产下拉、枚举)声明在组件定义旁,不是面板里硬编码。
- 带文档的字段会在悬停时显示说明;核心组件(如 Transform)不可删除,删除其他组件会先让你确认。
- 进入 Play / Simulate 后属性面板按运行规则变只读,与"运行中不改场景结构"一致。

## 运行控制

- `Play` 用场景的主摄像机渲染;`Pause` 暂停并把视角切回编辑器摄像机;再按一次继续。
- `Simulate` 只跑物理 / 动画,**不跑游戏脚本**;再按一次结束。`Stop` 结束 Play 并清理运行态。
- 运行中不允许改场景结构(增删组件、改父子关系、重绑脚本等会被拒绝),先 Stop 再改。

## 布局

- Window 菜单里有独立窗口面板、停靠面板分组与 `Reset Layout`;菜单里的分组标题只是标题,点不动。
- 面板可以拖动重新停靠;从停靠区拖出的面板会浮动,关闭浮动面板会回到停靠树。
- 布局按项目/用户状态保存,下次启动自动恢复。
