# 常见问题

按"症状 → 先查什么"组织。更多构建期问题见[构建与运行](../../dev/build.md)。

## 起不来 / 闪退

| 先查什么 | 说明 |
| --- | --- |
| 工作目录 | 开发期宿主按相对路径找 DLL 与资产:从**仓库根**启动最省事;发行版从发行目录启动 |
| 构建配置是否混用 | `CMAKE_BUILD_TYPE` 与 `--config` 不同名会让产物落在另一条路径;旧 DLL 配新宿主也会加载失败 |
| 图形驱动 / 后端 | 项目清单 `renderer:` 选的后端要能用;运行只需要驱动支持,构建期才需要 Vulkan SDK |
| 日志最后几行 | 编辑器与 Runtime 把日志写到标准输出 / 标准错误,从终端启动就能看到 |

## 画面不对

| 症状 | 先查什么 |
| --- | --- |
| 视口是空的 | 编辑器不带参数时从**空场景**起步:确认已经打开场景,且场景里有相机 / 实体 |
| 材质或贴图丢了 | 资产是否被移动 / 改名;引用路径是相对内容根的 |
| 模型缩放或朝向不对 | 导入设置存在 `.wmodel` 里,改完要 **Reimport** |
| 阴影 / 抗锯齿 / 渲染倍率异常 | `Project Settings` 里的渲染开关可以先关掉再对比,缩小范围 |

## 保存 / 打开

| 症状 | 先查什么 |
| --- | --- |
| 资产打不开、提示版本不匹配 | 按提示重新导入(旧版模型资产用 Reimport) |
| 保存失败 | 文件是否被别的程序占用;目录是否可写 |
| 场景打开后引用是空的 | 引用指向的资产是否还在内容树里的原路径 |

## 日志与诊断

- 从终端启动编辑器 / Runtime,日志(含错误与崩溃前的最后几条)就在那个终端里。
- 复现问题时先固定一个小场景、关掉无关设置项,再逐项打开,把"哪一项导致"说清楚。
